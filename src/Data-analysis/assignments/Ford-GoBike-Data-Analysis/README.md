# Ford GoBike Trip Data Analysis

## Project Overview

This project analyzes the Ford GoBike bike-sharing trip data for February 2019.

The analysis explores trip duration, user types, gender, member age, and station usage to identify patterns and insights in bike-sharing behavior.

## Dataset

The dataset contains 183,215 bike-sharing trips recorded during February 2019.

It includes information about:

- Trip duration
- Start and end stations
- User type
- Gender
- Member birth year
- Bike information
- Station locations

## Main Questions

- What is the distribution of trip durations?
- Which user type makes the most trips?
- How does trip duration differ between Customers and Subscribers?
- How does trip duration vary by gender?
- What is the age distribution of members?
- Is there a relationship between age and trip duration?
- Which starting stations are the most popular?

## Data Analysis

The project includes:

- Data Wrangling
- Data Assessment
- Data Cleaning
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Conclusions and Recommendations
